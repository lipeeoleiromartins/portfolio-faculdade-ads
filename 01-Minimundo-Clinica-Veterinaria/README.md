# Experiência Prática 1

## Sistema de Gestão para Clínica Veterinária Pet Vida Boa

### Objetivo

Desenvolver a análise de requisitos de um sistema para uma clínica veterinária.

### Funcionalidades

- Cadastro de tutores
- Cadastro de animais
- Agendamento de consultas
- Exames
- Tratamentos

### Competências

- Levantamento de requisitos
- Escopo do sistema
- Entidades de negócio
- Análise de dados
