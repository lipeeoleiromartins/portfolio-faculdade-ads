# Experiência Prática 3

## Normalização de Banco de Dados

### Objetivo
Aplicar as regras de normalização (Primeira, Segunda e Terceira Formas Normais — 1FN, 2FN e 3FN) nas tabelas do sistema da clínica veterinária Pet Vida Boa para eliminar redundâncias e garantir a integridade dos dados.

### Conteúdo
- **1FN (Primeira Forma Normal):** Eliminação de atributos multivalorados e grupos de repetição.
- **2FN (Segunda Forma Normal):** Remoção de dependências funcionais parciais.
- **3FN (Terceira Forma Normal):** Remoção de dependências transitivas.

### Resultado
Estrutura de dados relacional totalmente otimizada, normalizada e pronta para ser implementada em linguagem SQL.
